Authenticate a gated model HF_TOKEN

Export a read token approved for the model on the host. Forward it before the Docker image name.

Route model downloads https_proxy

LLMD checks https_proxy, HTTPS_PROXY, all_proxy, and ALL_PROXY in that order. The first nonempty value wins.

Disable reporting DO_NOT_TRACK

Disable crash and usage reporting. Use LLMD_NO_USAGE_STATS=1 to disable usage statistics only.

Profile the device LLMD_PROFILE_DEVICE_ONLY

Choose device-only tracing when profiling is enabled. The default is 0.
