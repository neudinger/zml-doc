Model access

Hugging Face hf://
Set
HF_TOKEN takes precedence.
Empty
Skips the token file.
Unset
Tries $HOME/.cache/huggingface/token, then anonymous access.
Amazon S3 s3://

AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY sign requests when both are set.

AWS_ENDPOINT_URL takes precedence over AWS_ENDPOINT_URL_S3. AWS_REGION takes precedence over AWS_DEFAULT_REGION.

Defaults https://s3.amazonaws.com and us-east-1.

Google Cloud Storage gs://

Use GOOGLE_APPLICATION_CREDENTIALS to select an ADC file. When unset, ZML looks for the gcloud ADC file on Linux and macOS.

Without a usable file, the loader can try GCE metadata, then anonymous access.

Runtime diagnostics

XLA_FLAGS passes compiler options to the selected backend. TF_CPP_MIN_LOG_LEVEL sets its log threshold.

Backend settings
