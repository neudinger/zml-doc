# Executable recipes

Store versioned scripts and explicit recipe definitions here. Authored recipe
pages belong in `content/recipes/` and published recordings in
`assets/recordings/`.

A future recipe definition should identify its product/version, source revision
or container digest, model/revision/precision when relevant, environment,
commands or complete source files, expected result, recording/transcript, and
verification evidence/date/status.

Use source-reviewed, executed, or experimental status. Do not mark a recipe
executed until it has run on the declared configuration. Normal site builds must
not execute recipes or update their verification dates.
